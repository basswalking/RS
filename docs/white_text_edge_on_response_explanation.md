# 白底黑字为什么容易产生很高的 ON 值

本文用当前程序的 ON/OFF 感受野算法，解释为什么一张白底黑字图片导入后，ON 值会明显升高。

## 1. 当前算法

对每个像素点，程序取：

- 中心点亮度：`center`
- 周围 8 个采样点亮度：`surround_1 ... surround_8`

然后计算：

```text
response = 8 * center - (surround_1 + surround_2 + ... + surround_8)
```

判断规则：

```text
response > 0  => ON 响应
response < 0  => OFF 响应
```

也就是说，算法检测的不是“整张图有多白”或“黑字有多少”，而是检测一个局部区域里：

```text
中心是否比周围更亮
```

如果中心点是白色，而周围采样点有一部分落在黑字上，那么 `center` 很高、`surround` 被黑字拉低，`response` 就会变成很大的正数，也就是强 ON 响应。

## 2. 一个具体例子

假设白底黑字边缘附近有一个白色中心点：

```text
center = 255
```

周围 8 个采样点中，有 `k` 个落在黑字上，亮度近似为 0；剩下 `8-k` 个仍然落在白底上，亮度近似为 255。

那么：

```text
surround = k * 0 + (8 - k) * 255
response = 8 * 255 - surround
response = 2040 - (8 - k) * 255
response = k * 255
```

所以只要周围 8 个点里有任何一个点采到黑字，响应就会变成正数：

```text
k = 1 => response = 255
k = 2 => response = 510
k = 4 => response = 1020
k = 8 => response = 2040
```

这就是白底黑字边缘容易产生高 ON 值的核心原因。

## 3. 同一个边缘点在 1-10px 半径下的例子

下面假设同一个白色中心点位于黑字边缘附近。不同 RF 半径会让 8 个周围采样点落到不同位置，因此每个半径下采到黑字的点数 `k` 不同。

当前程序使用的空间频率如下：

| RF 半径 px | cyc/deg | 中心亮度 | 采到黑字的周围点数 k | response = k * 255 | 极性 |
|---:|---:|---:|---:|---:|:---|
| 1 | 22.40 | 255 | 3 | 765 | ON |
| 2 | 11.20 | 255 | 4 | 1020 | ON |
| 3 | 7.47 | 255 | 5 | 1275 | ON |
| 4 | 5.60 | 255 | 5 | 1275 | ON |
| 5 | 4.48 | 255 | 4 | 1020 | ON |
| 6 | 3.73 | 255 | 3 | 765 | ON |
| 7 | 3.20 | 255 | 2 | 510 | ON |
| 8 | 2.80 | 255 | 2 | 510 | ON |
| 9 | 2.49 | 255 | 1 | 255 | ON |
| 10 | 2.24 | 255 | 1 | 255 | ON |

这个例子说明：只要中心仍在白底上，而周围采样点能碰到黑字，10 个不同空间频率下都可能产生 ON 响应。

## 4. 为什么导入图片比摄像头拍摄更容易 ON 飙高

导入图片通常有非常锐利的黑白边缘：

```text
白底 ~= 255
黑字 ~= 0
```

所以边缘附近的亮度差接近最大值，单个点的 response 可以达到几百甚至上千。

摄像头拍摄时，边缘会被镜头、对焦、压缩、曝光、纸面反光等因素软化。例如：

```text
白底 ~= 220
黑字边缘 ~= 80
```

如果同样有 4 个周围点采到黑字边缘：

```text
response = 8 * 220 - (4 * 80 + 4 * 220)
response = 1760 - 1200
response = 560
```

而理想导入图片中同样位置是：

```text
response = 8 * 255 - (4 * 0 + 4 * 255)
response = 2040 - 1020
response = 1020
```

所以同一个黑字边缘，导入图片的局部 ON 响应可能接近摄像头拍摄的 2 倍。

## 5. 结论

白底黑字图片的 ON 值高，是因为：

```text
大量白色中心点 + 周围采样点碰到黑字边缘
=> center 高、surround 低
=> 8 * center - surround 为大正数
=> ON 响应升高
```

导入图片边缘越锐利、白底越接近纯白、黑字越接近纯黑，ON 响应越强。
